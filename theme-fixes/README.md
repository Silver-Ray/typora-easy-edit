# Claude 主题行内代码光标修复

已直接应用到本机 `%APPDATA%\Typora\themes\claude.css` 和 `claude-dark.css`。
在 Typora 中切换到其他主题，再切回原主题，即可重新加载样式。

原来的 `.md-pair-s.md-expand` 规则把所有成对行内语法的标记压成零宽、零高，
导致光标位于反引号标记上时无法绘制。修复将隐藏规则限制为加粗、斜体，
并在行内代码编辑时恢复可见反引号、正常字号和橙色光标，添加不占布局空间的细边框。
打印时隐藏反引号编辑标记。

原始文件备份保存在各主题旁边，后缀为 `.inline-code-caret.bak`。
如需重新应用，在本项目目录执行 `node theme-fixes/apply.cjs`；重复执行不会重复添加规则。
也可以在命令末尾传入其他 Typora 主题目录。

`inline-code-caret.css` 是独立补丁。`apply.cjs` 还会修正原主题中过宽的隐藏选择器。

验证使用 Typora 实际行内代码 DOM、基础样式及本机 Claude 主题，在隔离 Chromium 预览中
检查浅色/深色、修复前/修复后，以及反引号前后四个光标位置，共 16 种状态。
修复前折叠选区的高度为 0，修复后为正常字高（本机预览为 14–18px），
同时确认加粗标记保持隐藏、打印时不显示反引号。截图及几何结果保存在 `previews/`。
